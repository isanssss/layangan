**LAYANGAN — War of Strings** — a kite-fighting duel game over an Indonesian kampung at dusk. Fly a glass-stringed fighter kite with real physics: a verlet string leashes you to a rooftop handler, monsoon gusts shove both kites around, and when your string crosses a rival's at speed the abrasion saws through it — dive across their line to cut it faster. One verb: PUTUS (cut). Beat seven named rivals — Si Kuning, Banteng Merah, Elang Perak, Kembar Mendung, Nyi Roro, Raja Langit, and the huge black JANDA HITAM — as the sky deepens from gold afternoon to starry night, choosing a string upgrade after every win (sharper gelasan, longer line, waxed coating, twin glass), then chase an endless streak in Langit Bebas mode. Vanilla JavaScript and Canvas 2D with synthesized WebAudio wind, string-zing and gamelan plucks — no libraries, no assets, no network.

## Run it

```sh
node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`node serve.ts` serves the game at http://localhost:8080 — open it in a desktop browser to play. The second command builds the entry: it copies `game/` and `screenshots/` to the output directory and writes the dossier the judges read.
